# gosay 사용법

**https://kyeongseok-go.github.io/gosay/**

## 처음 한 번

1. 아이폰 사파리로 위 주소를 연다
2. 공유 버튼 → **홈 화면에 추가**
3. 홈 화면 아이콘으로 연다 (사파리 탭이 아니라 설치한 앱으로 열어야 전체 화면이 되고 오프라인이 된다)
4. 첫 세션에서 녹음 버튼을 누르면 마이크 권한을 묻는다. **허용**을 누른다

> 앱을 이미 설치했는데 화면이 안 바뀌었다면, 앱을 **완전히 닫았다 다시 열어야** 새 버전을 받는다.

## 한 세션

첫 화면에서 **오늘 연습 시작**을 한 번 누르면 바로 시작한다. 카드 한 장이 네 박자다.

| 박자 | 하는 것 | 버튼 |
| --- | --- | --- |
| 1 듣기 | 소리만 듣는다. 아직 따라 하지 않는다 | 재생 → 들었다, 다음 |
| 2 겹쳐 말하기 | 음원을 틀고 **동시에** 따라 말한다 | 재생 → 따라 말했다, 다음 |
| 3 가린 채 말하기 | 영어가 사라진다. **한국어만 보고** 입으로 낸다 | 녹음 → 말했다, 들어 보기 |
| 4 대조와 채점 | 기준 음원과 내 녹음을 번갈아 듣는다 | 막혔다 / 더듬었다 / 바로 나왔다 |

**3박자가 이 앱의 전부다.** 1·2박자만 하면 그냥 듣기 앱이 된다. 도저히 안 나오면 *도저히 안 나오면 열기* 를 눌러 영어를 보고 말한 뒤, 정직하게 **막혔다**를 고른다.

## 채점을 정직하게 하는 법

채점이 다음에 언제 다시 나올지를 정한다. 그래서 잘 보이려고 할 이유가 없다.

- **막혔다** — 입이 안 떨어졌다. 간격이 초기화되고 **같은 세션 안에서 한 번 더** 나온다
- **더듬었다** — 나오긴 했는데 끊겼다. 간격은 그대로 두고 조금 더 자주 나온다
- **바로 나왔다** — 생각하지 않고 나왔다. 다음에는 더 멀리 간다

## 자주 쓰는 길

- **중단하면 그 자리에 그대로 있다.** 지하철에서 내려 앱을 닫아도, 다시 열면 *이어서 하기* 가 뜬다
- **묶음** 화면에서 묶음 하나만 골라 연습할 수 있다. **면접 직전에는 '못 들었을 때' 15장만 돌리는 것이 가장 쓸모 있다**
- **기록** 화면의 *막힌 문장* 이 지금 약한 곳이다. 거기만 따로 보면 된다
- **설정 → 내 문장** 에서 직접 문장을 넣을 수 있다. 넣은 문장은 기준 음원이 없어 브라우저 음성으로 읽는다

## 알아 둘 것

- **네트워크가 없어도 전부 된다.** 음원이 앱 안에 들어 있다. 지하철에서 쓰라고 그렇게 만들었다
- **녹음은 이 폰 안에만 있다.** 서버로 가지 않고, 문장마다 최근 3개만 남는다
- **마이크를 거부해도 연습은 막히지 않는다.** 녹음 없이 소리 내어 말하고 넘어가면 된다
- **사파리 사생활 보호 창에서는 저장이 안 된다.** 일반 창에서 쓴다
- 백업은 **설정 → 백업 → 내보내기**. 복습 기록과 설정만 담기고 녹음은 들어가지 않는다

## 문장을 고치고 싶을 때

영어가 입에 안 붙으면 고치는 게 맞다. 번들 문장은 앱에서 고치지 않고 코드에서 고친다:

```bash
cd ~/workspace/gosay
# src/content/interview.json 에서 그 문장의 en 을 고친다
pnpm audio      # 고친 문장의 음원을 새로 만든다
pnpm test && pnpm e2e
scripts/deploy-pages.sh
```

한국어는 승인된 문안(`고경석_채용사이트_입력원고_AX.md`)에서 온 것이라 그대로 둔다. **영어만 고친다.**
