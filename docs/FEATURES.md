# gosay 기능 명세

> 출퇴근 10분에 영어 면접 문장을 입으로 반복해서, **아는 문장이 아니라 나오는 문장으로** 바꾸는 개인용 PWA.
> 결정의 근거와 바꾸지 않을 것은 `HANDOFF.md` 에 있다. 이 파일은 무엇을 만들었고 무엇이 남았는지만 적는다.

구현 현황 2026-10-30 · 배포 https://kyeongseok-go.github.io/gosay/

## 기술 결정

| 무엇 | 무엇으로 | 왜 |
| --- | --- | --- |
| 뼈대 | Vite 8 + React 19 + TypeScript + Zustand + Dexie + HashRouter + vite-plugin-pwa | godo 에서 이미 검증된 설정을 그대로 복사했다 |
| 저장 | IndexedDB 만. 서버도 계정도 없다 | 혼자 쓴다 |
| 쓰기 경로 | ChangeSet 하나 (`commit(cs)`) | 메모리와 DB 가 조용히 어긋나는 길을 아예 없앤다 |
| 순수 함수 | 오늘·지금·id 를 **인자로 받는다**. `Date.now()` 를 부르지 않는다 | 시간 모킹 없이 월말·윤년·연말을 직접 넣어 본다 |
| 기준 음원 | 빌드 때 맥 `say` + `afconvert` 로 만들어 번들 (`scripts/make-audio.mjs`) | API 키·가입·네트워크가 전부 불필요하다. 42개 0.76MB |
| 내 녹음 | `MediaRecorder`, mime 탐지로 iOS 는 `audio/mp4` | iOS Safari 는 `audio/webm` 을 지원하지 않는다 |
| 채점 | 사람이 3단계로 스스로 채점 | 음성 인식은 설치한 PWA 의 iOS 에서 없을 수 있다 |
| 디자인 | godo 토큰(`src/styles/tokens.css`)을 그대로. 세션 화면만 글자를 키우고 버튼을 하나로 | 지하철에서 한 손으로 쓴다 |

## 기능

### A. 데이터·저장
- [x] A1 `Sentence`: 한국어·영어·트랙·묶음·메모·출처·음원 경로·직접 추가 여부
- [x] A2 `Review`: 다음 복습일, 간격, ease, 연속, 마지막 채점, 누적 막힘
- [x] A3 `Session`: 날짜, 카드 목록, 현재 위치와 박자, 채점 — **매 박자마다 저장**
- [x] A4 `Recording`: 녹음 Blob 을 IndexedDB 에, 문장마다 최근 3개만
- [x] A5 JSON 내보내기·가져오기 (녹음 제외, 남의 백업은 거절한다)
- [x] A6 스키마 버전 (Dexie `version(1)`, 올릴 때 `upgrade` 를 붙인다)

### B. 세션 (핵심)
- [x] B1 세션 생성: 복습 예정 먼저, 남는 자리에 신규. 하루 분량은 설정에서
- [x] B2 카드 4박자 화면. 버튼은 아래쪽 한 줄, 한 손 엄지로 끝까지 간다
- [x] B3 녹음·재생·A/B 대조. 권한 거부·미지원이면 녹음만 빠지고 흐름은 그대로
- [x] B4 3단계 자기 채점 → 복습 간격 계산 (순수 함수, TDD)
- [x] B5 중단·재개. 앱을 닫았다 열어도 같은 자리
- [x] B6 세션 끝 요약: 말한 문장 수, 막힌 문장, 다음 복습 예정

### C. 복습 설계
- [x] C1 간격 반복: 바로 나왔다 → 간격 × ease / 더듬었다 → 간격 유지 + ease 깎기 / 막혔다 → 초기화 + 같은 세션 안에서 다시
- [x] C2 밀린 복습 상한 (`catchUpCap`, 기본 12장)
- [x] C3 "막힌 문장만" 모아 보기 (기록 화면, 많이 막힌 순)

### D. 콘텐츠
- [x] D1 트랙 1 **면접 영어** 27장 (목표 60장에는 못 미친다 — STATE.md '못 한 것') — 자기소개 5 / 경력 설명 6 / 프로젝트 STAR 6 / 지원 동기 3 / 강점·약점 4 / 역질문 3
- [x] D2 트랙 1-b **못 들었을 때** 15장
- [x] D3 트랙 2 업무 기술 영어 40장 (코드 리뷰 12 / 스탠드업 10 / 설계 논의 10 / 문서·PR 8)
- [x] D4 트랙 3 짧은 것 25장 (회의 9 / 전화 8 / small talk 8)
- [x] D5 문장 직접 추가 + 런타임 TTS (번들 문장은 앱에서 고치지 않는다 — 사실 원장과 어긋난다)
- [x] D6 음원 생성 스크립트 (`pnpm audio`)

### E. 기록·설정
- [x] E1 기록 화면: 연속일, 최근 2주 막대, 막힌 문장 top
- [x] E2 설정 화면: 하루 분량, 상한, 속도, 트랙, 라이트·다크, 내보내기·전체 삭제
- [x] E3 PWA: 설치 가능, 오프라인 동작, 음원 포함 (미리 받기 1.34MB / 58항목)
- [x] E4 접근성: 키보드만으로 조작, axe 라이트·다크 통과, 명암비 AA, reduced-motion
- [x] E5 반응형: 320/375/390/768/1024/1440 가로 넘침 0px. 기준 화면 390×844

## 일부러 뺀 것

- **음성 인식 발음 채점** — 크롬은 음성을 서버로 보내고(오프라인 아님), iOS 는 네트워크 의존이며 설치한 PWA 에서는 아예 없을 수 있다. 지하철에서 앱이 죽는다. 자기 채점으로 대체했다
- **단어 암기·문법 설명·문법 퀴즈** — 아는 것이 문제가 아니라 안 나오는 것이 문제다
- **게임화(배지·하트·랭킹·연속 기록 압박)** — 연속일은 보여만 주고 재촉하지 않는다
- **AI 대화 상대·실시간 교정** — API 키가 필요하다. 1차 범위 밖이다
- **외부 사전·번역 연동** — 네트워크
- **계정·동기화** — 혼자 쓴다. 필요해지면 JSON 백업부터
- **실행 취소** — godo 와 달리 문서를 고치는 앱이 아니다. 되돌릴 것이 채점 하나뿐이라 값이 없다

## 검증 명령

```bash
pnpm exec tsc -b     # 타입
pnpm lint            # oxlint + 디자인 토큰 검사
pnpm test            # 단위
pnpm coverage        # 커버리지 임계값
pnpm e2e             # 프로덕션 빌드를 preview 로 띄워서
pnpm audio           # 코퍼스를 고쳤을 때 음원 다시 만들기
node scripts/shoot.mjs       # 스크린샷 (shots/)
node scripts/check-live.mjs  # 배포본 점검
scripts/deploy-pages.sh      # 배포
```
