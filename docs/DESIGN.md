# gosay 디자인 근거

> 수치를 지어내지 않는다. 아래 값은 **godo 에서 이미 레퍼런스를 열어 재 둔 것**이거나,
> 이 프로젝트에서 **브라우저로 직접 잰 것**이다. 어느 쪽인지 표에 적었다.

## 방향

godo 와 같은 가족이되, **세션 화면만 다르다.**

godo 는 정보를 빽빽하게 담는 화면이고, gosay 의 세션 화면은 그 반대다 — 글자가 크고, 한 번에 하나만 두드러지고, 버튼이 아래쪽 한 줄에 모여 있다. 지하철에서 한 손 엄지로 쓰기 때문이다. 그래서 godo 의 토큰은 그대로 가져오되 세션 화면에서는 밀도를 일부러 낮췄다.

## 가져온 값

| 값 | 무엇 | 어디서 |
| --- | --- | --- |
| 반경 10 / 14 / 20 / 26 / 알약 | 카드·면·틀·버튼 | godo 실측 (gif.garajedeideas.com 전수 집계) |
| 120ms / 200ms / 320ms | 미세 반응 / 주력 / 넓은 이동 | godo 실측 (gif.garajedeideas.com · refero.design) |
| `cubic-bezier(0.23, 1, 0.32, 1)` | easeOutQuint. 넓게 움직이는 것 | godo 실측 |
| `cubic-bezier(0.34, 1.4, 0.64, 1)` | 눌림 스프링. **transform 에만** 쓴다(끝값이 1 을 넘는다) | godo 실측 |
| 44pt 최소 터치 영역 | 손가락이 닿는 모든 것 | Apple HIG |
| 자간 부호 반전 | 본문은 조이고(-0.016em) 큰 제목은 벌린다(+0.008em) | Apple SF Pro 트래킹 표 |
| 그림자 대신 채움색 | 얹힌 면은 색으로, **뜬 것만** 그림자로 | godo 실측 (iOS 묶음 목록) |
| 알약 하나로 묶은 띄운 독 | 바닥에 붙이지 않고 띄운다 | godo 실측 |

## 이 프로젝트에서 직접 잰 것

### 명암비 때문에 바꾼 것 (전부 실측 후)

| 토큰 | 전 | 후 | 왜 |
| --- | --- | --- | --- |
| `--muted` | `#6c6c70` | `#636368` | `--fill-3`(#ececf1) 위에서 4.44 로 AA 미달. 세 화면에서 같은 원인으로 걸렸다 |
| `--stuck-ink` 외 2개 | `--danger` 등을 그대로 | 짙은 짝을 새로 둠 | 각 색의 14% 틴트 위에서 3.57~3.79 로 미달 |
| `.btn__hint` | `opacity: 0.75` | 투명도 없음 | 틴트 배경에서 4.4 로 미달. 라벨과의 구분은 크기·굵기가 한다 |

## 세션 화면이 godo 와 다른 점

| 무엇 | godo | gosay 세션 |
| --- | --- | --- |
| 한 화면의 결정 수 | 여럿 | **하나** (다음 박자로 갈까 / 어떻게 채점할까) |
| 영어 문장 크기 | — | `--text-xl` (28~34px). 화면의 주인공이다 |
| 버튼 위치 | 화면 곳곳 | **아래 한 줄**. 엄지가 닿는 자리 |
| 채점 버튼 배치 | — | 가로가 아니라 **세로로 쌓는다**. 한 손으로 고른다 |
| 색의 뜻 | 상태·우선순위 | 막혔다/더듬었다/바로 나왔다 **세 단계** |

## 일부러 안 한 것

- **박자가 바뀔 때 화면 전환 애니메이션** — 10분에 32번 바뀐다. 매번 움직이면 멀미가 난다. 눈금만 채워진다
- **녹음 중 파형·레벨 미터** — 보는 동안 입이 멈춘다. 색 하나로만 알린다
- **연속일 압박(불꽃·배지)** — 숫자만 보여 주고 재촉하지 않는다
- **새 레퍼런스 전수 집계** — 이번 밤에는 하지 않았다. godo 의 실측값이 그대로 유효하고, 시간을 3단계 배포에 썼다. 다시 한다면 세션형 학습 앱(Speak·말해보카)의 **세션 화면**을 열어 한 화면당 버튼 수와 글자 크기를 재는 것부터다
